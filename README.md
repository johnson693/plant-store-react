# 🌿 GreenLeaf Plant Store

A modern plant e-commerce web application built with **React 19** and **Vite**.

## 🚀 Tech Stack

- **React 19** — with React Compiler for automatic optimization
- **Vite 8** — lightning-fast build tool
- **Lucide React** — clean icon library
- **ESLint** — code quality with React Hooks plugin

## ✨ Features

- Browse trending and top-selling plants
- Add to cart with wishlist support
- Filter plants by category
- Newsletter subscription
- Fully responsive design
- O₂ air-purifying plants section

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
